# Vibe Coding

> A web-based coding environment with AI assistance, real-time collaboration, and a Monaco-based editor.

A Next.js application featuring a code editor, authentication, database integration, and WebSocket support.

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |

## Tech Stack

- **Framework:** Next.js 16 + React 19
- **Styling:** Tailwind CSS 4
- **Editor:** Monaco Editor
- **Database:** Neon (PostgreSQL) via Drizzle ORM
- **Auth:** NextAuth v5
- **Reality:** WebSocket support
